## Machine Intelligence Assignments

A collection of simple assignments completed individually for a University of Canterbury course, [COSC401](https://courseinfo.canterbury.ac.nz/GetCourseDetails.aspx?course=COSC401&occurrence=26S1(C)&year=2026).

Questions build on one another and typically include sample tests for verification. Test code and files, peripheral files, function and class signatures as well as `ass2/read_data.py` are copied from the assignment briefs themselves and should be attributed to [Kourosh Neshatian](https://profiles.canterbury.ac.nz/Kourosh-Neshatian).
